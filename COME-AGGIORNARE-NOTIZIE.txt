  COME AGGIORNARE LE NOTIZIE DEL SITO
  Convitto "Costaggini" — Rieti
════════════════════════════════════════════════════════

Per aggiungere una nuova notizia basta modificare il file
"notizie.json" con un editor di testo (Blocco Note va bene).

COME AGGIUNGERE UNA NUOVA NOTIZIA:

1. Apri "notizie.json"
2. Copia e incolla questo blocco IN CIMA all'elenco,
   subito dopo il primo "[":

  {
    "id": "nome-univoco-senza-spazi",
    "data": "Maggio 2026",
    "categoria": "Istituzionale",
    "titolo": "Il titolo della notizia",
    "testo": "Il testo completo della notizia, anche lungo.",
    "link": "https://www.facebook.com/alberghierorieti/...",
    "link_testo": "Leggi su Facebook →",
    "immagine": "https://images.unsplash.com/photo-XXXXX?w=600&q=80",
    "immagine_alt": "Descrizione breve dell'immagine per accessibilità",
    "in_evidenza": true
  },

3. Salva il file
4. Ricarica il sito — la notizia appare automaticamente in homepage

NOTA: Le prime 3 notizie del file appaiono in homepage.
      Tutte le notizie appaiono in notizie.html.

PER L'IMMAGINE:
- Usa un'immagine da Unsplash (unsplash.com, gratuita)
- Oppure carica una foto nella cartella "img/" e scrivi: "img/nomefile.jpg"

  GALLERIA FOTOGRAFICA (SLIDESHOW) DI UNA NOTIZIA
════════════════════════════════════════════════════════

Cliccando sulla foto di una notizia può aprirsi uno slideshow
con altre foto dell'evento. Per attivarlo:

1. Carica le foto nella cartella "img/notizie/nome-evento/"
   (es. img/notizie/tutti-a-scuola/01.jpg, 02.jpg, ...).
   Se accanto a una foto .jpg c'è la versione .webp con lo
   stesso nome, il sito userà quella, più leggera.

2. Apri "gallerie.json" e aggiungi una voce. La chiave è la
   foto di copertina, cioè esattamente quanto scritto nel campo
   "URL immagine" della notizia:

  "img/notizie/tutti-a-scuola/copertina.jpg": {
    "titolo": "Titolo mostrato in alto nello slideshow",
    "foto": [
      { "src": "img/notizie/tutti-a-scuola/01.jpg", "alt": "Descrizione per accessibilità", "didascalia": "Testo facoltativo sotto la foto" },
      { "src": "img/notizie/tutti-a-scuola/02.jpg", "alt": "..." }
    ]
  }

   Facoltativo: "mini" indica una miniatura leggera per la
   fila in basso (es. "img/notizie/tutti-a-scuola/01-mini.webp").
   La copertina diventa da sola la prima foto dello slideshow,
   se non è già nell'elenco.
   Se la copertina è solo un ritaglio di una foto dell'elenco,
   aggiungi  "includi_copertina": false  per non ripeterla.
   Tra una voce e l'altra ci vuole la virgola.

3. Salva: la foto della notizia diventa cliccabile (il cursore
   diventa una lente). Nessun pulsante compare sulla pagina.
   Lo slideshow scorre da solo (6 secondi per foto), si può
   mettere in pausa e si naviga con frecce, miniature e swipe.

Esempio già attivo: la notizia "Tutti a scuola" di Amatrice,
con copertina "img/notizie/tutti-a-scuola/01.jpg".
